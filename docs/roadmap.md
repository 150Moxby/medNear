# MOXORA roadmap

## Phase 0: Foundation
- repository setup
- architecture and roadmap documentation
- product framing and risk awareness

## Phase 1: Core workspace
- monorepo structure
- dashboard shell
- API health endpoint
- database schema foundation
- setup guidance and environment variables

## Phase 2: Editor and project operations
- file explorer
- Monaco editor shell
- terminal and diagnostics
- project persistence

## Phase 3: Runtime and compiler tools
- Node.js, Python, and C/C++ execution services
- runtime and compiler registry
- validation and sandbox testing

## Phase 4: AI and project memory
- coding assistant
- agent management and audit logs
- memory context handling

## Later phases
- design tooling, cloud automation, collaboration, mobile, marketplace, academic/community features

## Status

The project is intentionally staged to prioritize real implementation and secure execution before broad platform expansion.
