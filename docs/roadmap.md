# MOXORA roadmap

## Phase 0: Foundation
- repository setup and product framing
- architecture and module boundaries
- roadmap, risks, and scope definitions

## Phase 1: Core workspace
- monorepo structure
- web dashboard and navigation shell
- API health and database schema foundation
- environment and setup documentation

## Phase 2: Editor + project operations
- Explorer and project management
- Monaco editor and file persistence
- terminal and diagnostics panel
- basic Git integration

## Phase 3: Runtime and compiler tools
- Node.js, Python, and C/C++ execution boundaries
- compiler registry and runtime management
- sandboxed execution and validation

## Phase 4: AI and memory
- coding assistant foundation
- AI task management, approval boundaries, and audit logs
- project memory and context management

## Phase 5: Design, API, and data
- DesignSpace and component design flows
- API Studio and schema designer
- backend and auth tooling

## Phase 6: Test, security, cloud, and collaboration
- QA, security checks, deployment automation
- team presence, collaboration, and shared previews
- cloud workloads and deployment resources

## Phase 7: Mobile, game, AI models, hardware, and marketplace
- mobile and tablet flows
- game and hardware experimentation
- marketplace and academy features

## Status

The roadmap is intentionally structured to prioritize working software and secure execution before broader platform expansion. MOXORA Studio is not production-ready at this stage.
